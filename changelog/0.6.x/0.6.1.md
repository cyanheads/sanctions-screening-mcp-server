# 0.6.1 — 2026-11-11

## Added

- **`sanctions_screen_name`** includes published birth dates, nationalities, and address countries where available, on both response surfaces. (#83)
- **Input normalization** accepts mixed-case LEIs for entity lookup, ownership tracing, and the entity resource. Name screening and entity resolution clamp oversized page limits to 100 and 50 with a notice. Set `SANCTIONS_NORMALIZE_INPUTS=false` to restore strict validation. (#82)

## Changed

- **Tool discovery** shortens output descriptions while retaining continuation and screening guidance. Identifier screening documents all eleven supported lists, subject to mirror coverage. (#84) (#85)
- **MCP bundles** strip dependency agent docs while retaining runtime modules.
- **Bun** requires 1.4.4 or later when running under Bun.

## Fixed

- **`sanctions_screen_name`** keeps unknown-type designations eligible when filtering by entity type, in both strict and fuzzy matching. (#78)
- **`sanctions_screen_identifier`** matches OFAC company IMO numbers with or without the prefix. Existing mirrors rebuild the identifier index on open and preserve the published identifier label and value. (#79)
- **`sanctions_resolve_entity`** reports strict matches excluded by registration status when the filtered strict pass is empty, with counts by status and guidance to try `status: "any"`. (#80)
- **CSL dates** normalize calendar-valid US start dates to ISO on refresh and retain other nonblank published text. (#81)
- **Scheduled refresh** skips a run when another process holds the sync lease.
