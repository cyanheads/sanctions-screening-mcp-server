# 0.6.0 — 2026-10-31

## Added

- Publish a sanctions-screening guide over MCP for resolving ambiguous identities and following up on incomplete investigations.
- **BIS and State coverage** adds Entity, Denied Persons, Unverified, Military End User, ITAR Debarred, and Nonproliferation Sanctions lists through one keyless CSL download, retaining published identifiers, restrictions, notices, and provenance ([#76](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/76)).

## Changed

- **`sanctions_trace_ownership`** pages nodes, edges, and branch boundaries with query-bound cursors, 50 default/100 maximum records, and a soft 64-KiB target that retains oversized records intact; drain pages before following same-side boundaries ([#27](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/27)).
- **Coverage and vetting guidance** distinguishes unloaded CSL lists, successful local sync timestamps, unresolved identity, and incomplete accounting-consolidation graphs; refresh existing mirrors to populate the new lists.
- **Distribution and tooling** delivers the guide in npm, Docker, and MCPB, adds Agent Plugins root manifests, updates framework development guidance, and excludes build-only bundle files while retaining SDK skill runtime modules.
- **Bun** 1.4.3 → 1.4.4 in the package-manager pin and Docker stages.
