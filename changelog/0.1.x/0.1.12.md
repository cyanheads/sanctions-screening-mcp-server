# 0.1.12 — 2026-09-20

## Changed

- **Bun engines floor rises to `>=1.4.0`** — required by the framework mirror driver's SQLite `close(true)` fix.
- **An out-of-schema tool call returns `InvalidParams` (`-32602`)** with `data.reason: "invalid_arguments"`, a schema-derived `data.recovery.hint`, and a `Recovery:` line in `content[0].text` — where it returned `ValidationError` (`-32007`) before. A client branching on the error code must change.
- **Tool error text closes with `(reason <reason> · not retryable)`** whenever the error data carries a `reason` or a boolean `retryable`; `structuredContent` is unchanged.
- **A snake_case or kebab-case spelling of a declared argument** (`min_score` → `minScore`, `match_mode` → `matchMode`, `entry_id` → `entryId`, `screen_nodes` → `screenNodes`) is rewritten to the declared key instead of rejected; a client-added root key is dropped, and a JSON-stringified array is repaired once on a failed parse. The advertised `inputSchema` is byte-identical.
- **A caller disconnect mid-call classifies `RequestCancelled` (`-32011`)** instead of `InternalError`, and that request's SSE stream closes immediately.
- **An upstream 500 or 501 from a sanctions source classifies `ServiceUnavailable`** (a 500 now retries), and a 3xx classifies `InvalidRequest`.
- **The server card at `/.well-known/mcp.json` publishes the resolved session mode** under `_meta`.
- **Session posture is declared `stateless` in `src/index.ts`**, matching the `.env.example` and Docker image, which already pinned it.
- **Shutdown closes both SQLite mirror handles through the framework's `teardown` hook** — prepared statements release with the file instead of pinning it until garbage collection.

## Fixed

- **`node-cron` declared as a dependency (#28)** — the framework's `scheduleRefresh()` needs it as an optional peer; undeclared, the sanctions-mirror refresh job failed to register on every HTTP boot.
