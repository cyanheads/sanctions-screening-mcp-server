# 0.1.7 — 2026-07-04

## Fixed

- **`ScreeningService`** admission for the whole-string fuzzy arm (shared by `runFuzzy` and `runLeiFuzzy`) now also requires the folded query and candidate to fall within a 0.5 length ratio (shorter ÷ longer) before admitting on whole-string Jaro-Winkler alone — the shared-prefix boost otherwise lets a short single-token alias admit an unrelated multi-token query it merely prefixes (`jaroWinkler("nicolas maduroo moros", "nicolas")` = 0.8667, above the 0.85 default floor, at 1/3 token coverage). The token-coverage arm and every surfaced score (raw Jaro-Winkler, never composite) are unchanged. ([#8](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/8))
- **`lengthRatio()`** new exported primitive in `text-matching.ts` — shorter folded string length over longer, in [0, 1] — backing the guard above.
