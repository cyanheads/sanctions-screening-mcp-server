# 0.1.11 — 2026-08-25

## Added

- **Cache hints across the surface.** `createApp({ cacheHints })` lets a 2026-07-28 client hold `tools/list`, `prompts/list`, `resources/list`, `resources/templates/list`, and `server/discover` for an hour, scoped `public`. Per-record lifetimes sit on the resource definitions: an hour, `private`, on `sanctions://designation/{source}/{entryId}` and `sanctions://entity/{lei}`; `ttlMs: 0` on `sanctions://sources`, whose payload is the mirror's own freshness.
- **`MCP_SESSION_MODE` in the README environment table.** The Docker image already pinned `stateless`; `.env.example` now does too — no tool here suspends for caller input.

## Changed

- **Tool inputs are strict at the root.** An undeclared argument key is rejected by name (`Unrecognized key: "min_score"`) instead of being stripped before the handler runs, so a caller that guessed a parameter name gets an error rather than a default-valued result.
- **Advertised schemas moved to JSON Schema 2020-12**, every tool's root `inputSchema` carries `additionalProperties: false`, and `outputSchema` declares the error envelope as an `anyOf` between the success fields and `error`.
- **Protocol revision 2026-07-28** is served on the HTTP endpoints and reported by `/.well-known/mcp.json`; a client that negotiates 2025-06-18 through `initialize` still gets a session and is otherwise unaffected.
- **`Dockerfile` builds on `oven/bun:1.4.0`** on both stages, with the build stage pinned to `$BUILDPLATFORM` — bun ≥ 1.4 aborts under QEMU, so the `linux/amd64` leg of a multi-arch build has to compile natively. `packageManager` follows to `bun@1.4.0`.
- **Repo tooling tracks the framework:** the bundled `skills/`, `changelog/template.md`, and the `lint:mcp` / `lint:packaging` definition checks (`@modelcontextprotocol/sdk` → `@modelcontextprotocol/server` on the bundle's critical-path list). None of these ship in the npm package.

## Fixed

- **Documented parameter names match the schemas.** `README.md`, `docs/design.md`, `.env.example`, and the `SANCTIONS_FUZZY_MIN_SCORE` descriptions in `server.json` named `min_score`, `match_mode`, `entity_type`, `entry_id`, and `match_type`; the tools declare `minScore`, `matchMode`, `entityType`, `entryId`, and `matchType`. Under strict root inputs the old names are rejected rather than ignored, so the correction is part of that change, not cosmetic.
- **README MCP SDK badge** read `^1.29.0`; the framework moved to `@modelcontextprotocol/server` `^2.0.0`.
