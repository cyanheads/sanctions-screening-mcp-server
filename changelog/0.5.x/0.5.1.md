# 0.5.1 — 2026-10-20

## Changed

- **Scheduled refreshes** run in a supervised child process, keeping committed indexes readable during writes; timeout and teardown cancel, reap and release the writer for the next run ([#70](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/70)).
- **Approximate screening** compares Russian-alphabet romanizations in both directions while retaining published names and native strict matching; derived equality remains approximate, never an official alias or identity determination ([#57](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/57)).
- **Framework references and checks** follow the adopted framework release; Bun development and Docker images use 1.4.3.

## Fixed

- **Fuzzy candidate recall** supplements native candidates with indexed early-letter deletion signatures within existing pool budgets ([#69](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/69)). Existing typed GLEIF mirrors gain the supplemental index through out-of-band `mirror:refresh`.
- **Approximate scores** render the exact structured numeric value in both screening and entity-resolution text responses ([#74](https://github.com/cyanheads/sanctions-screening-mcp-server/issues/74)).
